# Project brief template

Copy, fill what you know, and paste it into the Motion Studio project. Leave anything blank — the planner fills it with a default and tells you.

```
PROJECT IDEA:
(one or two sentences — what the video is and who it's for)

BRAND / CLIENT:            name, website URL (if any)
WHERE IT PLAYS:            LinkedIn / Reels / TikTok / YouTube / X / landing page / ad / keynote
THE ONE TAKEAWAY:          the single sentence the viewer must remember
LENGTH:                    e.g. 30s
FORMATS:                   9:16 / 1:1 / 4:5 / 16:9
VIDEO TYPE (optional):     showreel · product-launch · mascot-explainer · ui-morph-loop · ui-film-set ·
                           kinetic-pitch · data-story · logo-sting · story-history · music-video · narrative-short

BRAND LOOK:                colors (hex), fonts, logo file (SVG best), looks to avoid
STYLE:                     a vault style (ink-and-signal, warm-paper-ui, swiss-grid-mono, neon-night-pop,
                           soft-watercolor, or one you saved) — or "new look"
REFERENCE:                 a video/frame/folder whose pacing or look you like (grammar only)

VOICE:                     none / narrator / talking mascot — tone, language, gender/age if it matters
CAPTIONS:                  on / off
MUSIC:                     synthesize (mood: drive, bright, cinematic, lofi, minimal, piano) / my own track (owned or licensed)

CONTENT I HAVE:            script/notes, product screenshots, data (with source), mascot art, track
DEADLINE / REVISIONS:      date · number of revision rounds (default 2)
```

## Example
```
PROJECT IDEA: 45s explainer for my agency that writes and runs newsletters for startup founders.
BRAND / CLIENT: Inkwell Founders, inkwellfounders.com
WHERE IT PLAYS: LinkedIn and Instagram Reels
THE ONE TAKEAWAY: Founders get a weekly newsletter in their voice without writing it themselves.
LENGTH: 45s     FORMATS: 9:16, then 1:1
VIDEO TYPE: mascot-explainer
BRAND LOOK: #1C1B19 ink, #F3EFE7 paper, accent #E2553B; fonts Inter Tight + Inter; logo.svg
STYLE: warm-paper-ui
VOICE: warm, confident narrator, English, mid-pace. Mascot: original — up to you
CAPTIONS: on     MUSIC: synthesize, bright
CONTENT I HAVE: logo.svg, two sample newsletter screenshots
DEADLINE: Friday, 2 revision rounds
```
