# Ink & Signal — signature

**Seed style** (ships with the studio). Replace these notes with real ones the first time a project uses and refines it (`npm run vault -- save <slug> --update ink-and-signal`).

## The look in one line
Near-black ink canvas, warm paper type, one hot orange signal. Tight grotesk display, mask-up words, quiet moving grid, light grain.

## Signature moves
- One accent only — orange marks the single thing to look at
- Huge type for hooks, small UI type for labels
- Text reveal: `mask-up` · transitions: `wipe` · pace: `snappy`

## Don't
- No gradients
- No glow on UI
- Nothing centered-on-gradient

## Pairs well with
- Music: drive, 120 BPM, minor
- Voice: calm, low, confident
- SFX: clicks, swipes, one impact on the lockup
