# Swiss Grid Mono — signature

**Seed style** (ships with the studio). Replace these notes with real ones the first time a project uses and refines it (`npm run vault -- save <slug> --update swiss-grid-mono`).

## The look in one line
Off-white page, black heavy caps, a single red. Strict column grid, slide-in type, data drawn with thin rules. Editorial and factual.

## Signature moves
- Everything aligns to the column grid
- Numbers huge, labels in mono
- Text reveal: `slide` · transitions: `slide` · pace: `snappy`

## Don't
- No rounded corners
- No more than one red element per frame

## Pairs well with
- Music: minimal, 110 BPM, ticks
- Voice: neutral, newsroom pace
- SFX: ticks on numbers, one impact per chapter
