# Warm Paper UI — signature

**Seed style** (ships with the studio). Replace these notes with real ones the first time a project uses and refines it (`npm run vault -- save <slug> --update warm-paper-ui`).

## The look in one line
Warm neutral canvas, ink UI, one cobalt accent. Product-film UI motion: containers morph, content swaps behind a short blur, springs with a hair of overshoot.

## Signature moves
- Real UI only, rounded device-less frames
- Shadows soft and short
- Text reveal: `blur-in` · transitions: `zoom` · pace: `smooth`

## Don't
- No bouncy easing on containers
- No gradients on UI chrome
- No particle bursts

## Pairs well with
- Music: bright, 120 BPM, soft drums
- Voice: warm, friendly, mid-pace
- SFX: ui clicks, soft pops, typing
