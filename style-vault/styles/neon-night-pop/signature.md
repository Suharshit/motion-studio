# Neon Night Pop — signature

**Seed style** (ships with the studio). Replace these notes with real ones the first time a project uses and refines it (`npm run vault -- save <slug> --update neon-night-pop`).

## The look in one line
Deep night canvas, drifting magenta/cyan mesh, acid-lime accent. Chunky rounded display type that scale-pops on the beat. High energy, social-first.

## Signature moves
- Cut on every beat in the drop
- Lime accent for the one word that matters
- Text reveal: `scale-pop` · transitions: `zoom` · pace: `bouncy`

## Don't
- No thin type
- No slow fades

## Pairs well with
- Music: drive, 124-128 BPM, four-on-the-floor
- Voice: hype, fast, smiling
- SFX: risers into impacts, claps
