# Soft Watercolor — signature

**Seed style** (ships with the studio). Replace these notes with real ones the first time a project uses and refines it (`npm run vault -- save <slug> --update soft-watercolor`).

## The look in one line
Cold-press paper, translucent pigment washes, soft serif display. Slow cinematic springs, blur-in type, heavy paper grain. Storybook warmth.

## Signature moves
- Edges bleed; nothing perfectly vector
- Line boil every 2 frames
- Text reveal: `blur-in` · transitions: `fade` · pace: `cinematic`

## Don't
- No hard drop shadows
- No neon

## Pairs well with
- Music: piano, 90 BPM, sparse
- Voice: soft, storyteller, unhurried
- SFX: paper rustle, soft chimes
